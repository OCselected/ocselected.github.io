  • 29,000+ developers

The report additionally documents that openEuler was featured at Huawei HC 2026 (2026-09-17 to 2026-09-19), that openEuler 26.09 (the September innovation release) added full-scenario innovation capabilities and new AI-scenario features — Agent observability, SkillHub context management, KV Cache collaborative acceleration, model loading optimization — and that openEuler 24.03 LTS SP4 RISC-V (RVA23) extended support for JindieShikong V100, Lanxin Lianli LX500 and other server platforms. The report names openEuler Meetup Chengdu (2026-09-26) with space computing and operating system as the central theme — participants from central authorities, industry experts, university scholars, and industry partners discussing space new-infrastructure, intelligent computing base, and on-orbit operating system ecosystem cooperation. The report’s September technical progress section is a concentrated AI-observability-and-agent-factory layer: Agent Router in dual-card inference automatically routes requests to Chat-expert or Coder-expert models based on request intent, improving correctness by approximately 5 percent; Ops Agent SkillHub conversational operations-assistant covers 16 classes of routine work — fault diagnosis, daily inspection, CVE patching, security hardening, performance tuning, storage management, network management, kernel maintenance, high-availability and cluster, container and virtualization, system upgrade and rollback, backup and recovery, account and permission, service and process, log audit, and knowledge sedimentation; KPBot turns Kunpeng performance optimization from expert experience to intelligentized; openEuler witty-agent-factory provides a unified visual entry point for the local Agent ecosystem to help developers and project administrators complete Agent viewing, building, validation, release, and process tracking; PP-OCR Benchmark runs through on openEuler 24.03.

Institutional significance: The openEuler September 2026 operations report is the first-documented instance in this series of the Chinese-open-source-community operational-report surface being operationalized at the emergent-ecosystem-operations layer simultaneously with this series’ prior Aug 8, Aug 25, Sep 11, Sep 23, and Oct 4 briefings’ documentation of the openEuler surface at the administrative-open-source-and-administrator-facing-open-source layer — a two-surface-simultaneous institutional-form observation on the same institutional object.

From an institutional economics perspective, the report matters on four axes:

First, the aggregate dataset (10 million+ users + 29,000+ developers + 2,199 organization members + 112 SIG + 340,800 PR + 167,500 Issue + 6,225,400 Comment) is institutionally the observation object of “the ecosystem is a result, not a means” — a structurally new institutional-economics fact. The dataset is not a set of administrative-construction KPIs (deployment quantity, vendor onboarding, government procurement) but a set of emergent-ecosystem operations indicators — user count, developer count, organization-member count, SIG count, PR count, Issue count, Comment count. From an institutional economics standpoint, this administrative-KPI-set / emergent-operations-indicator-set pairing is a structural finding: the same Chinese-open-source-community institutional surface this series’ prior briefings have documented at the administrative-construction-and-administrator-facing layer is now being observed at the emergent-ecosystem-operations layer. The institutional-economics reading is that the operational-report surface is not a compliance artifact reporting how much administrative work has been done — it is a governance artifact reporting how much emergent ecosystem operation has accumulated.

Second, Wang Tao’s HC 2026 keynote figure — “openEuler, after seven years, has surpassed 20 million installed instances and holds the China server operating system #1 share” — is an institutional-economics fact about the administrative-open-source-vs-emergent-open-source distinction. Wang Tao’s framing is that openEuler “has been empowering thousands of enterprises’ application services, serving multiple countries and regions globally, driving the construction of a new global open source ecosystem and creating a new paradigm for China’s open source development.” From an institutional economics standpoint, this Wang-Tao-seven-year-narrative / openEuler-20-million-installed pairing is a structural finding: openEuler is being claimed simultaneously as (a) an emergent open-source ecosystem (20 million installed, China #1 share, global multi-country deployment) and (b) a new paradigm for China’s open source development — an administrative-open-source-narrative claim. The Great Divergence 2.0 framework’s core distinction (real open source = FLOSS emergent community vs. pseudo open source = administrative-construction project) is being operationalized here on the same institutional surface: openEuler is empirically both an emergent open-source ecosystem (per the operations-report dataset) and an administrative-open-source narrative claim (per Wang Tao’s keynote framing). The institutional-economics reading — this series’ consistent reading — is that these two institutional identities are not contradictory, they are complementary surfaces on the same institutional object, and the operational-report surface documents the emergent-community scale layer that the administrative-construction KPI surface cannot.

Third, the September technical progress section (Agent Router, SkillHub, KPBot, witty-agent-factory, PP-OCR) is an institutional-economics fact about the open-source agent-observability-and-factory layer. The Agent Router’s dual-card dual-expert routing with 5 percent correctness improvement, the SkillHub’s 16-class operations coverage, KPBot’s Kunpeng-performance-optimization-expert-to-intelligentization transition, and witty-agent-factory’s unified visual entry point for local Agent ecosystem development — together, these constitute an emergent open-source Agent-observability-and-factory layer at the operating-system level. From an institutional economics standpoint, this Agent-Router-dual-expert / SkillHub-16-class-ops / KPBot-Kunpeng-intelligentization / witty-agent-factory-local-ecosystem pairing is a structural finding: the operating-system open-source surface is now being operationalized at an AI-agent-infrastructure layer that this series’ prior four-week October briefings have documented at the frontier-lab-agent-infrastructure layer (DeepSeek Harness, Moonshot Kimi K3) but not at the operating-system open-source layer. The institutional-economics reading is that the operating-system open-source surface (openEuler) is not being operationalized as a passive hosting substrate for frontier-lab agents but as an active agent-factory-and-observability substrate — a structurally new institutional-form observation.

Fourth, the report’s community-event list (HC 2026, Chengdu meetup, national health services forum, China-ASEAN Expo, Witty-to-East-China-universities) is an institutional-economics fact about the open-source surface’s diplomatic-and-education-expansion layer. From an institutional economics standpoint, this HC-2026-global-deployment / Chengdu-space-computing / health-services-forum-AI-native / China-ASEAN-Expo-digital-intelligence-finance / Witty-East-China-universities pairing is a structural finding: openEuler is being operationalized at a five-surface-simultaneous institutional-form layer (industry conference, regional technical meetup, base-level health services, international diplomatic expo, higher-education extension) that this series’ prior briefings have documented at the single-surface-layer but not at the five-surface-simultaneous layer. The institutional-economics reading is that openEuler is not one institutional object but one institutional object simultaneously operationalized across five institutionally distinct surfaces — the emergence of a multi-surface operational pattern at the Chinese-open-source-community scale layer.

2. Domestic database outlet (via 国产数据库 official channel, 2026-10-10) — “Purchasing pseudo-domestic is now lifetime-reckoning; Xinchuang selection criteria have changed again; the cobra effect is only intensifying”

3. State-owned Assets Supervision and Administration Commission of the State Council — Measures for Investigating and Holding Accountable for Violations in Central Enterprise Operations and Investment (SASAC Decree No. 46)

4. Ministry of Industry and Information Technology + Central Cyberspace Affairs Commission + Central Government Procurement Center (June 2026) — New rules on government, party, and state-informatization new-and-modified systems requiring full-stack Xinchuang adaptation and code-chain-full-link audit

5. State Council Office Document No. 2025-34 — Government procurement domestic-product standard; domestic products enjoy bidding price-review preference from this year

6. SASAC Instruction No. 79 — Xinchuang transformation completion target: end of 2027, full replacement, “should replace, must replace”

8. National Testing Announcement No. 1 of 2023 — 11 database evaluation certifications expiring 2026-12-25; non-renewal invalidates eligibility

The 2026-10-10 domestic-database-outlet piece on SASAC Decree No. 46 is the first-documented instance in this series of the Xinchuang-institutional-surface being operationalized at the lifetime-reckoning-and-personalized-reckoning layer simultaneously with the cobra-effect-plus-forgery-technology-amplification layer. The piece reads the three policy lines together:

The SASAC Decree 46 line. Decree No. 46 is titled “Measures for Investigating and Holding Accountable for Violations in Central Enterprise Operations and Investment.” Article 12 writes “producing, selling, or purchasing pseudo-innovation and pseudo-domestic products” into the accountability list. The core message: buying a relabeled or shoddy fake-domestic product is no longer just a “project-failure” question — it is a lifetime accountability question for the person who signed off. Article 4 sets lifetime accountability for major decisions. Article 35 specifies that collective decision members are held separately — collective decision is not an exemption. Article 51 closes off the escape route: retirement, benefit adjustment, transfer, resignation — accountability continues, and where state-asset loss is caused, compensation obligations can be pursued. Penalties are maximum severity: direct responsible persons face 100 percent deduction of annual performance pay plus 100 percent deduction of term incentives plus forfeiture of the preceding three years’ medium- and long-term incentive income, with severe cases leading to demotion and lifetime prohibition from state-owned enterprise service.

The June 2026 MIIT-CAC-Central-Purchasing-Procurement-Center line. New rules require that government, party, and state-informatization new-and-modified systems meet full-stack Xinchuang adaptation and code-chain-full-link audit requirements. Systems that do not meet the bar are disqualified from bidding and acceptance. This is a compliance gate on the procurement-award side.

The State Council Office Document No. 2025-34 line. From this year, government procurement establishes a domestic-product standard and domestic products enjoy bidding price-review preference. This is a compliance gate on the market-entry side.

The SASAC Instruction No. 79 timeline pressure. Instruction No. 79’s target is end of 2027 completion of Xinchuang transformation, full replacement, “should replace, must replace.” Only slightly more than a year remains from the 2026-10-10 publication date.

The market-scale backdrop. Q1 2026 financial Xinchuang tender scale rose more than 40 percent year-on-year; the full-year 2026 Xinxuang market is projected at 2.66 trillion yuan. Volume is expanding rapidly.

The National Testing Announcement No. 1 of 2023 expiration. 11 database products entered the national testing registry under 2023 Announcement No. 1 — the evaluation validity period expires 2026-12-25. Products not re-certified before then lose eligibility. This is a compliance gate on the vendor-product-eligibility side.

Institutional significance: The 2026-10-10 SASAC Decree 46 piece is the first-documented instance in this series of the Xinchuang-southeast-side-of-stratification institutional surface being operationalized at the lifetime-reckoning-and-personalized-reckoning layer simultaneously with the cobra-effect-plus-forgery-technology-amplification layer — a two-surface-simultaneous institutional-form observation paired with this series’ Oct 9 briefing’s documentation of the Xinchuang-northwest-side-of-stratification (head-of-stratification slowdown) institutional surface being operationalized at the value-based-rollout-and-business-first-and-risk-controlled layer.

From an institutional economics perspective, the Decree 46 piece matters on four axes:

First, the three-line pairing (SASAC Decree 46 lifetime accountability + June 2026 full-stack-audit new rules + State Council Office Document 2025-34 domestic-product bidding preference) is institutionally the conversion of Xinchuang procurement from “support domestic” to “personally accountable” — a structurally new institutional-economics observation on the same institutional object this series’ Oct 9 briefing documented at the head-of-stratification slowdown layer. The Decree 46 piece’s sharpest institutional sentence is: “The three lines are twisted together — the direction is clear: Xinchuang procurement is shifting from supporting domestic products to personal accountability.” From an institutional economics standpoint, this support-domestic-narrative / personal-accountability-narrative pairing is a structural finding: Xinchuang procurement has been documented in this series at the administrative-narrative-support layer (this series’ Aug 3, Aug 19, Sep 11, Sep 18, Sep 23, Sep 30, Oct 2, Oct 4, Oct 8 briefings) and at the value-based-rollout-and-business-first layer (this series’ Oct 9 briefing), but not at the personal-accountability layer. The institutional-economics reading is that Xinchuang procurement is now a three-layer institutional object: (i) administrative-narrative-support layer, (ii) value-based-rollout-and-business-first layer, (iii) personal-accountability-and-lifetime-reckoning layer. The three layers are not alternatives — they are simultaneously operating surfaces on the same institutional object, and Decree 46 is the third layer being activated.

Second, the individual-victim-selection-logic inversion (from “cheapest and pretty-parameter” to “won’t get in trouble”) is an institutional-economics fact about the cobra-effect-plus-evidence-chain-hard-currency transition. The Decree 46 piece explicitly names the selection-logic inversion: “In the past, one chose the cheapest, the pretty-parameter. Now one chooses the non-incident-risk.” And: “How the tender document is written is how the evidence chain must be preserved.” Source code, audit reports, national-testing evaluation level, real deployment cases — the items that used to be bonus items are now becoming hard currency. From an institutional economics standpoint, this cheap-and-pretty-selection / non-incident-risk-selection pairing is a structural finding: Xinchuang procurement has been converted from a quality-and-cost-optimization problem (cheapest + pretty-parameter) into a risk-and-accountability-avoidance problem (non-incident-risk + full evidence chain). The institutional-economics reading is that the accountability layer is not just adding a compliance gate — it is inverting the selection-optimization objective function from quality-cost trade-off to risk-avoidance-first. This is a structurally new institutional-form observation about procurement as an optimization problem whose objective function has been rewritten.

Third, the explicit cobra-effect-plus-Yangquan-horse-skin-analogy pairing is an institutional-economics fact about the forgery-technology-amplification mechanism. The Decree 46 piece explicitly invokes the cobra-effect — the classic case in which colonial India offered a bounty per dead cobra to reduce cobra populations, resulting in people breeding cobras to kill them for the bounty, and after the bounty was cancelled releasing the bred cobras into the wild, increasing the cobra population. It also invokes the 1980s Yangquan (Shanxi) horse-skin bounty case — where people killed healthy horses to sell their hide for the bounty, increasing horse deaths. The piece’s sharpest institutional sentence: “All three Xinchuang policy lines are triggering the cobra effect — Decree 46’s lifetime-reckoning for pseudo-domestic will cause vendors to research how to forge real domestic; full-stack Xinchuang plus code-chain audit will cause vendors to research how to forge auditable evidence chains; State Council Office Document 2025-34’s domestic-product standard will cause vendors to research how to forge domestic-product status.” From an institutional economics standpoint, this cobra-effect-narrative / forgery-technology-amplification-mechanism pairing is a structural finding: the accountability-and-compliance-layer addition is not a one-way ratchet — it is a two-way incentive structure in which the stricter the compliance and the higher the personal accountability, the higher the forgery-technology incentive. This is not a critique of Decree 46 or the compliance layer — it is an empirical observation that compliance-and-accountability layers, in isolation, activate forgery-technology amplification, and that the only institutional answer to the forgery-technology-amplification mechanism is code-level proof-of-domestic (the Decree 46 piece’s sharpest closing sentence: “Whoever can prove ‘I am real domestic’ to the code level can make it into the next short list”). The institutional-economics reading is that the accountability layer has activated a forgery-technology counter-selection — a selection pressure on the vendor side that the accountability layer itself does not directly address.

Fourth, the “more orders but fewer signers” paradox (2.66 trillion yuan annual Xinchuang market + Q1 financial Xinchuang 40%+ year-on-year tender growth + 79 Instruction 2027 completion target + Decree 46 lifetime accountability) is an institutional-economics fact about the compliance-amplified market-volume-amplified accountability-amplified signing-contracted paradox. From an institutional economics standpoint, this market-volume-amplification / signing-contracting pairing is a structural finding: Xinchuang is now a market in which volume is expanding (2.66 trillion yuan annual, 40%+ Q1 financial growth), accountability is expanding (Decree 46 lifetime-reckoning), timeline is contracting (79 Instruction 2027 completion), and vendor-eligibility is contracting (2023 Announcement No. 1 expiration 2026-12-25). All four institutional pressures are moving in the direction of a smaller signing population in a larger market. The institutional-economics reading — this piece’s sharpest institutional sentence — is that the volume-amplification and accountability-amplification pairing is not producing a “healthy market” (in the sense of more participants and more accountability) — it is producing a compressed signing population in an expanding market — a structurally new institutional-form observation.

🔍 Commentary#

Two stories, one institutional pattern: administrative-construction-adjacent surfaces activating emergent-and-accountable institutional identities.

This cycle’s two stories document, on two different institutional surfaces, the same unsolved institutional pattern: the administrative-construction-adjacent institutional surface activating an emergent-and-accountable institutional identity this series’ prior briefings have not documented at before.

  • openEuler September 2026 operations report documents the Chinese-open-source-community operational-report surface at the emergent-ecosystem-operations layer — the aggregate dataset (10 million+ users, 29,000+ developers, 2,199 organization members, 112 SIG, 340,800 PR, 167,500 Issue, 6,225,400 Comment) is not an administrative-KPI artifact but an emergent-ecosystem-operations artifact; paired with the operating-system-level AI-agent-infrastructure layer (Agent Router, SkillHub, KPBot, witty-agent-factory, PP-OCR); paired with the five-surface-simultaneous institutional-form layer (HC 2026, Chengdu meetup, health-services forum, China-ASEAN Expo, Witty East China universities). This is the openEuler surface this series’ prior Aug 8, Aug 25, Sep 11, Sep 23, and Oct 4 briefings documented at the administrative-open-source-and-administrator-facing layer — now observed at the emergent-ecosystem-operations layer.
  • SASAC Decree 46 + June 2026 full-stack-audit new rules + State Council Office Document 2025-34 documents the Xinchuang-institutional-surface at the lifetime-reckoning-and-personalized-reckoning layer — Article 4 lifetime accountability, Article 35 collective-decision-members-held-separately, Article 51 post-retirement/post-transfer/post-resignation accountability retained; paired with the selection-logic-inversion layer (from cheap-and-pretty-parameter to non-incident-risk with evidence chain as hard currency); paired with the cobra-effect-plus-forgery-technology-amplification layer (breeding-cobra bounty analogy, Yangquan horse-skin case generalized to Xinchuang compliance as forgery-technology-selection-pressure); paired with the volume-amplification-plus-accountability-amplification-plus-timeline-contracting-plus-eligibility-contracting paradox layer (2.66 trillion yuan annual + Q1 40%+ growth + 79 Instruction 2027 target + 2023 Announcement No. 1 expiration 2026-12-25). This is the Xinchuang surface this series’ Oct 9 briefing documented at the head-of-stratification slowdown layer — now observed at the tail-of-stratification accountability-activation layer.

The two stories together document that two Chinese-institutional surfaces this series’ prior Oct briefings have documented at the administrative-construction-adjacent layer are now being operationalized at two new institutional layers simultaneously:

  • openEuler moves from administrative-construction-adjacent to emergent-ecosystem-operations — the operational-report surface is the emergent-community-scale layer, not the administrative-KPI layer.
  • Xinchuang moves from administrative-construction-adjacent to lifetime-reckoning-and-personalized-accountability — the Decree 46 surface is the personal-accountability layer, not the administrative-narrative-support layer.

One structural observation across both stories.

The structural observation, reading the two stories together, is that both surfaces are being operationalized at institutional layers this series’ prior briefings have documented at the frontier-lab-institutional-architecture layer but not at the Chinese-open-source-community-and-Xinchuang-institutional layer. This series’ prior four October briefings (Oct 6, Oct 7, Oct 8, Oct 9, Oct 10) documented the frontier-lab institutional object (DeepSeek, Moonshot AI, HKIC-BAAI) at the sovereign-capital-plus-voting-rights-plus-CITIC-Securities-STAR-IPO institutional layer. This cycle’s briefing documents that the same sovereign-institutional-identity-plus-personal-accountability institutional pattern is now being operationalized at the Chinese-open-source-community-and-Xinchuang-institutional layer — the two institutional objects that this series has tracked throughout its 52 prior briefings.

The institutional-economics reading, in this series’ standard framing, is that the two new layers — emergent-ecosystem-operations on openEuler and lifetime-reckoning-plus-cobra-effect on Xinchuang — are not the same institutional form as the frontier-lab sovereign-capital-plus-voting-rights-plus-CITIC-Securities-STAR-IPO form. They are different institutional surfaces of the same institutional pattern: the Chinese state is operationalizing the frontier-lab-institutional-architecture pattern (sovereign capital, personal accountability, compliance-as-hard-currency) at the Chinese-open-source-community-and-Xinchuang-institutional layer.

One perspective, not a verdict.

All two stories — openEuler September 2026 operations report and SASAC Decree 46 — are best read as observations of institutional movement in progress, not as verdicts on institutional direction. The openEuler operations-report dataset does not guarantee that openEuler’s emergent-ecosystem-operations layer will remain emergent (it may be captured by the administrative-construction layer); the Decree 46 accountability layer does not guarantee that the cobra-effect plus forgery-technology amplification will not intensify (the piece’s own sharpest closing sentence is the warning); the 2.66 trillion yuan annual Xinchuang market does not guarantee that the compressed-signing-population-in-an-expanding-market paradox will resolve (the piece’s sharpest institutional sentence is the warning). What this cycle’s briefing documents is that the Chinese-open-source-community-and-Xinchuang-institutional objects this series has tracked throughout its 52 prior briefings have crossed a first-documented threshold — from the administrative-construction-adjacent layer to two new institutional layers (emergent-ecosystem-operations and lifetime-reckoning-plus-cobra-effect) — and that the two new layers sit on the same unsolved institutional pattern: the administrative-construction-adjacent surface activating an emergent-and-accountable institutional identity.
