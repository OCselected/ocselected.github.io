(2) CAICT (中国信息通信研究院) launches the first batch of Agent Management Ability Maturity Assessment (AOMA) — a five-level maturity framework (Entry / Advanced / Excellent / Excellence / Leading) with a two-axis management-domain architecture (comprehensive management domain + full-process management domain), jointly designed with 50+ enterprises and nearly 100 experts, positioning itself as a third-party assessment-and-testing system for AI-native organizational capability — the first-documented CAICT-administrative-institute three-tier-agent-assessment-instrument surface in this series, operationalizing the agent surface this series’ September 17 briefing documented at the CAICT-administrative-institute three-layer-governance-framework layer and this series’ September 14 briefing documented at the MIIT ‘AI + Software’ Special Action Implementation Plan’s Agent Software Application Store + Skills Resource Library layer at the CAICT-administrative-institute-assessment-instrument layer simultaneously — a two-surface-simultaneous CAICT-administrative-institute-agent-assessment-instrument pattern.”
