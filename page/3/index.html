2026-10-13 「开源之道」·论文略读：AI Slop 之后——当 cURL 关掉 7 年的 Bug Bounty 项目

Min, Frluckaj, Gaughan, Champion, Crowston, Benjamin Mako Hill, James Howison (2026, ACM CSCW 2026 Companion Workshop, DOI 10.1145/3785651.3818817) 用 2026-01 cURL 关闭运行 7 年、累计 $100K+ 的 Bug Bounty 项目作为最锋利的实证锚点：AI slop 冲击的不是「贡献质量」而是「协作规范的生产机制」——过去关于 AI slop 的全部讨论都绕过了这个命题。Coleman 1990 社会资本理论的最新样本（AI slop = 没有社会资本的贡献）；Coase 1937《企业的性质》命题在开源场景的第六次精确化（bug bounty 被迫退回内部化）；Lerner-Tirole 2002 声誉机制在 AI 时代的第二次实证失效；Williamson L1-L4 四层框架在协作规范层的第一次完整应用；「开源公共品外部脆弱性」命题的多层化——AI 冲击（技术）+ 气候冲击（物理）+ 本文协作冲击（规范）三重证据链。开源四层制度基础设施第 15 层「协作规范层」的第一份社会科学学科化。

2026-10-09 「开源之道」·论文略读：社交热度冲击开源协作——739,587 名 GitHub 用户的开发者注意力与“太热点而不敢/不愿提交”实证

Han (2026, SSRN 10.2139/ssrn.7582038, Peking University) 用 739,587 名活跃 GitHub 用户的日级 commit 面板 × 逐日热度/注意力观测，within-user 差分识别社交热度对开发者产出的关联效应。发现一：超高热度与 commits 产出显著下降相关，且后续几天几乎没有恢复；发现二：地理上距离较远的协作对中，一方产出下降与另一方产出上升相关——分布式结构可能提供注意力挤占风险分散。Coase 1937《企业的性质》命题在开源场景的第五次精确化（开发者的注意力状态作为外部交易成本的一部分）。Williamson L1 社会嵌入层的最底层样本（L1 命题从企业决策跨主体扩展到个人产出的注意力嵌入）。Ostrom 边界界定原则的注意力层版本（Ostrom 从社会注意力公地到数字公地的完整闭环）。哈耶克自发秩序命题在开源场景的第一份社交热度冲击实证。与 #192 Katz (10-08) 的镜像对照：AI 冲击（技术外部冲击）+ 社交热度冲击（注意力外部冲击）构成开源公共品的双重外部脆弱性。开源四层制度基础设施第二层扩展：贡献者注意力层。
