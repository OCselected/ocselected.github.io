【思想札记】踩稳脚下的踏脚石：从《拿出办法来》看“开源下一代”的累积与涌现

在第十一届中国开源年会（COSCon'26）“开源下一代”开幕前夕，重读半导体泰斗胡正明教授的回忆录《拿出办法来》。从人类超越生物基因的社会性累积讲起，再以半导体的“踏脚石”铁律、SEMATECH 的“同桌共担”以及四十年产业“板块运动”为镜鉴：开源的实质是防止文明倒退的棘轮；下一代之所以能站在前人的肩膀上继续向前，靠的不是顶层规划的奇迹，而是自由市场与开放契约下生生不息的制度涌现。

明天（11月14日），第十一届中国开源年会（COSCon'26）就要在杭州正式拉开帷幕了[cite: 2]。今年组委会定下的主题是——“开源下一代，OpenSource: The Next Generation”，官宣长文里有一句话格外动人：“每一代开源人，都在为下一代开源铺路。”[cite: 2]

恰逢今天翻读“三维晶体管（FinFET）之父”、加州大学伯克利分校教授、台积电首任技术长胡正明（Chenming Hu）先生的回忆录《拿出辦法來：三維電晶體之父胡正明改變半導體世界的科學人生與科技思索》[cite: 3]。书页间流淌的半导体四十年演进史，与明天即将开启的“开源下一代”撞了个满怀[cite: 2, 3]。

在当下的商业与社会语境里，人们似乎更容易陷入存量博弈的焦虑与内卷。但每当我们把目光投向“下一代”这三个字时，叙事的底色瞬间就亮了起来。下一代，天然代表着希望、增长与发展，它是人类在面对漫长而充满不确定性的宇宙时，能够保持乐观、持续向前的最重要心理基础。

而当我们借着胡正明教授的科技思索，穿透代码与晶圆的表象，去审视人类文明演化的底层逻辑时，一条冷酷而迷人的规律便浮出水面：开源的实质，是让人类得以超越生物基因的桎梏，实现跨代际的智识累积；而“下一代”的自由探索与接力，正是开源生生不息的根本与力量来源。

一、 超越双螺旋的暴政：社会性与文明的“共同语言”#

在自然界的演化长河中，绝大多数物种的代际传递，都被死死地锁在 DNA 的双螺旋结构里。

一只猎豹奔跑的极限速度、一只海狸筑坝的本能，必须经历数万年极其缓慢的基因突变与残酷的自然选择，才能写入下一代的遗传密码。如果某只聪明的黑猩猩在丛林里偶然悟出了用特殊角度砸开坚果的巧劲，只要缺乏跨越个体的群体传递机制，一旦它死去，这项技艺就会随之湮灭。它的下一代出生时，面对的依然是混沌的起点，必须把前辈走过的弯路原封不动地再走一遍。

唯独人类，打破了生物基因的暴政。

人类是地球上唯一能够超越生物基因限制、进行大规模跨代际知识传递的物种。演化人类学家约瑟夫·亨里奇（Joseph Henrich）在《人类成功统治地球的秘密》中指出，我们仰仗的并非单个大脑的绝对算力，而是人类的**“社会性（Sociality）”**——语言、文字、法治契约、同行声誉，以及由此构建出的超大规模合作网络。这种“累积性文化演化（Cumulative Cultural Evolution）”构成了人类的第二套遗传系统：上一代人历经千辛万苦试错得出的“秩序（信息）”，可以直接打包沉淀为公共知识底座，成为下一代人出生时的默认起点。

芯片如此，汽车如此，一切现代复杂技术皆如此。

很少有圈外人知道，今天支撑起全球万亿级半导体产业、让无数芯片设计公司（Fabless）与晶圆代工厂（Foundry）能够精密分工协作的基石之一，其实是一个彻头彻尾的“开源”项目。早年，当晶体管尺寸不断微缩，在芯片真正流片制造出来之前，电路设计工程师怎么知道几十亿个晶体管在硅片上的物理表现？

胡正明教授与他在伯克利的团队从基础物理原理出发，开发出了紧凑晶体管模型 BSIM（Berkeley Short-channel IGFET Model）。在面临是否申请专利收费的路口时，他们做出了一个极具远见的决定：拒绝专利垄断，将 BSIM 的源代码免费开放给全球学术界与产业界使用。

这套开放的模型，瞬间成为了全球芯片设计与晶圆制造之间的“共同语言（Lingua Franca）”。这就如同 19 世纪英国工业革命时期，瓦特的蒸汽机专利到期后，康沃尔郡的矿山工程师们自发建立共享设计图纸与运行数据的“康沃尔蒸汽机公地（Cornish Engine Commons）”一样。因为有了 BSIM 这片开放公地，后来的无数年轻工程师与初创企业，不再需要各自关起门来重复推导底层的半导体物理方程，而是直接站在伯克利团队铺就的肩膀上，将算力与才华投向更高维度的架构创新（即 Larry Page 所说的“额外性 Additionality”）。

这就是开源在人类文明史上的本体论实质：它是防止人类智识倒退的终极“棘轮（Ratchet）”。它用开放的契约将前辈的成果锚定在公地上，免除了下一代人重复造轮子的沉重交易成本[cite: 4]。

二、 湍急河床上的“踏脚石”：功力是累积的，不是买来的#

既然开源的实质是跨代际的累积，那么这种累积在微观工程与时间维度上是如何发生的？在《拿出办法来》中，胡正明教授结合英特尔在 10 纳米制程上的历史性折戟，写下了一段令所有技术决策者背脊发凉的深刻洞察[cite: 3]：

“半导体制造的功力是累积学习的结果，是技术创新、良率改善、成本下降，以及在它之前每一个节点所学到的一切经验。每一个节点都是在前一个节点上的改进。没能把某一代做到完美，下一个节点就难开发得多……延误会层层下传。如果 10 纳米迟了，把它改进到一个节点的时间就更少，下一个节点出问题的几率也更高。竞争对手不会等你。客户会离开，人才会出走，投资人的耐心也会消失。这一跤偏偏跌在这个节骨眼上：台积电正在追上来，AI 也正为晶片产业带来前所未有的商机。2016 年的延误不只是错过预定时程，它是一张骨牌，推倒了其他的里程碑与机会。”[cite: 3]

读到这段话，任何一个对复杂系统演进有所体悟的人，都会立刻联想到肯尼斯·斯坦利（Kenneth O. Stanley）与乔尔·莱曼（Joel Lehman）在《为什么伟大不能被计划》中提出的**“踏脚石（Stepping Stones）”理论，以及诺贝尔经济学奖得主肯尼斯·阿罗（Kenneth Arrow）著名的“干中学（Learning by Doing）”**学习曲线[cite: 3]。

想象一条湍急的河流，河里露出间距相等的踏脚石[cite: 3]。每块石头都被前一块的高度托着——唯有结结实实地踩稳了脚下这一块，你才够得着下一块[cite: 3]。那些站在岸边死死盯着对岸“宏伟战略目标”、试图靠行政命令或资本砸钱一步跨过去的人，无一例外都会踩空落水[cite: 3]。

功力是“做过”之后沉淀在组织肌肉与社区网络里的默会知识（Tacit Knowledge），它只能靠时间累积，永远无法在市场上直接购买[cite: 3, 4]。 半导体从平面晶体管走向三维 FinFET，从 28 纳米、16 纳米、10 纳米一路演进到 2 纳米，每一代制程都是下一代的踏脚石，中断即意味着断代，良率与工程直觉是用钱买不回来的[cite: 3]。

开源软件的演进与代际传承，遵循着一模一样的“踏脚石”铁律[cite: 3]：

  • 版本链与社区信任的不可跳跃性： 在一个健康的开源项目中，每一个 Release（版本发布）都建立在前一个版本的试错与重构之上；每一次看似枯燥的 Code Review、每一场邮件列表里的架构争论、每一份公开透明的无指责故障复盘（Blameless Post-mortem），都是在踩实脚下的石头[cite: 3, 4]。
  • “大跃进”与硬分叉的必然溃败： 回看历史，从当年苏联计算机工业放弃自主演进、试图通过国家行政指令全面逆向工程（硬分叉白嫖）IBM System/360 的 ES EVM 计划悲剧[cite: 4]，到今天本土某些科层制巨头面对开源公地时习惯性的“拉取分支（Fork）—内部闭门魔改—发公关通稿宣称自主创新”[cite: 1, 4]，它们的共同病根都在于妄图跳过“踏脚石”[cite: 3]。为了迎合短期的 KPI 时程而欠下的技术债、对上游社区（Upstream）的冷漠透支、对维护者精力的榨取，都会像胡正明教授笔下那张倒下的 10 纳米多米诺骨牌一样，层层下传，最终在技术范式换代（如云原生向 Agentic AI 跃迁）的节骨眼上加倍讨回[cite: 1, 3, 4]。

真正的“开源下一代”，绝不是靠口号或运动式的补贴催熟出来的[cite: 2, 4]。够得着下一块石头，靠的是老老实实踩稳眼前的这一块[cite: 3]。

三、 同一张桌子与板块运动：制度引力下的自发秩序#

当技术演进的“踏脚石”越来越陡峭，当下一代创新的研发成本与复杂度突破了单一组织的承受极限时，人类该如何拿出办法来？

胡正明教授在书中截取了半导体史上的两个宏大历史切片，恰好构成了观察开源制度演化的绝佳双棱镜[cite: 3]：

1. 第一块切片：SEMATECH 与“同一张桌子”#

“把竞争者带到同一张桌子上：诺伊斯构想出一个对应日本合作模式的美国版本：由美国政府与领先的美国晶片制造商组成伙伴关系，共同投入资源，解决个别公司难以独立承担开发下一代晶片制造技术的问题。1987 年成立的 SEMATECH，是一个具有里程碑意义的产业与政府联盟。”[cite: 3]

为了竞争，为了未来，对手必须坐到同一张桌子上[cite: 3]。

这听起来充满悖论，却是新制度经济学与公共选择理论中最深刻的洞见[cite: 3]。正如詹姆斯·布坎南（James M. Buchanan）的“俱乐部品（Club Goods）”理论与曼瑟尔·奥尔森（Mancur Olson）的《集体行动的逻辑》所揭示的：先进制程的基础设备与材料研发，贵、险、周期长，任何一家公司独立承担都会面临高昂的试错风险與搭便车困境[cite: 3]。竞争者恰恰是最该同桌的人——因为他们面对的是同一个物理极限的难题，也最懂彼此的痛处[cite: 3]。

把视线移回数字世界，今天的开源基金会（如 Linux Foundation、CNCF、Apache 软件基金会，乃至新兴的 AAIF），本质上就是罗伯特·诺伊斯当年摆下的“那张长桌”[cite: 3, 4]。

但这张桌子之所以能成为孕育下一代创新的温床，而非退化为亚当·斯密所痛斥的“重商主义垄断卡特尔（Cartel）”[cite: 3, 4]，其核心判据只有一个：这张桌子的产出，是否对非成员无差别开放[cite: 3]？规则是否公开可议、自由退出是否可行[cite: 3]？ 就像中世纪波罗的海沿岸的商业城市为了分摊反海盗护航成本、降低度量衡摩擦而自愿缔结“汉莎同盟”一样[cite: 4]，科技巨头们在开源基金会的长桌旁各占一席，将各自最尖端的研发资源投进桌子中央，在公共基建层（公地）共担风险、共建标准，转身再去商业产品层与互补资产上展开激烈的市场博弈[cite: 1, 3, 4]。让死敌愿意并肩坐下来的，从来不是道德说教的善意，而是把“共担交易成本”变成理性最优解的那把制度椅子[cite: 3, 4]。

2. 第二块切片：四十年的“板块运动”与无人执笔的版图#

“如果英特尔无法吸引足够的外部代工客户，可能必须停止开发先进制程。这句话仿佛是罗伯特·诺伊斯四十年前那份担忧的回声：下一代晶片技术的开发成本太高，没有任何一家晶片公司能够独立承担。过去四十年间，一场板块运动稳定而无情地重画了晶片产业的版图。陈立武重申英特尔以晶圆代工模式汇集外部客户、创造规模的策略，就是这场运动最新、也最明显的证据。”[cite: 3]

胡正明教授用“板块运动”来形容台积电开创的晶圆代工（Foundry）模式如何彻底重塑了全球芯片产业，真是精准至极[cite: 3]。

在长达四十年的岁月里，两块大陆板块缓慢而无情地相互推挤；地面上的人只当日子如常，脚下却没有一寸版图是静止的[cite: 3]。几十年后回望，山脉、海沟、新的海岸线都已换了一副面孔——版图被彻底重画，却没有任何一位“总设计师”曾提前执笔画出过这张蓝图[cite: 3]。

这正是哈耶克（F. A. Hayek）所说的**“自发秩序（Spontaneous Order）”**——人类社会中最有用的制度，往往是人类行动的结果，而非人类设计的结果[cite: 3, 4]；这也是内森·罗森伯格（Nathan Rosenberg）在技术史研究中反复强调的：创新总是沿着没人预定的小径分岔演进[cite: 3]。

自由市场就是如此，计划往往以意想不到的方式落地[cite: 3]。今天我们看到 Linux 基金会成为全球数字世界庞大的中立基础设施组织，它难道是 2000 年初某位顶层规划者设计出来的吗[cite: 3, 4]？根本不是[cite: 3, 4]。它是市场主体为了应对 SCO 版权诉讼危机、为了避免 Linus Torvalds 受雇于单一商业公司引发信任崩塌、为了省去每个新领域重复注册非营利组织的法务成本，在一次次撞墙后不断打出的“契约补丁”[cite: 4]。

生态是演化的“果”，而不是顶层规划的“因”——凡是能被行政指令人为“构建”出来的，都不叫生态，那只是没有造血能力的数字盆景[cite: 3, 4]。

四、 开源下一代：在 AI 重组的板块上“拿出办法来”#

理解了社会性累积的本质、踏脚石的不可逾越以及板块运动的自发秩序，我们再来审视明天即将开幕的 COSCon'26，就会对“开源下一代（OpenSource: The Next Generation）”生发出一种超越技术热点的历史敬畏感[cite: 2, 3]。

正如大会官宣文中所敏锐捕捉到的[cite: 2]：

  • 技术与商业板块正在剧烈重写： AI 带来的真正冲击，不只是又一个技术风口，而是人类组织生产方式的根本改变[cite: 2]。生产单元正在从工业时代僵化的“公司科层部门”，演变为“人 + Agent + 社区 + 平台”的任务网络[cite: 2]。公司可以更小，网络可以更大；雇佣可以更少，基于开源许可证与同行声誉的异步协作可以更多[cite: 2]。
  • 价值分配与治理的新痛点： 当开放权重模型、数据集、Agent 协议（如 MCP、A2A）与全球社区贡献共同创造价值时，开源正在从单纯的代码仓库，演化为新商业文明的信任层、协作层与分配层[cite: 2, 4]。

在这场全新的、剧烈的板块运动面前，没有现成的教科书，也没有全知全能的规划者[cite: 2, 3, 4]。

这也让我再次想起《拿出办法来》书名的由来——当年胡正明教授出任台积电首任技术长，在面临棘手的工程与产业瓶颈时，张忠谋先生曾对他说过一句话，后来更将其镌刻在水晶牌上赠予他：“拿出办法来！（Find a way!）”[cite: 3]

这五个字，朴素得没有一丝修辞，却重若千钧。它不是坐在办公室里发号施令的官僚推诿，而是自由市场中的开拓者直面真实问题、调动一切智识去试错突围的担当[cite: 3, 4]。

面对“下一代开源技术、下一代开源人才、下一代开源社区、下一代开源商业”的重重未知[cite: 2]，谁能拿出办法来？

答案不在那些习惯了“圈地收租、算法围猎、搞微信群影子内阁伪治理”的掠夺性巨头的保密会议室里[cite: 4]，而在明天 COSCon'26 会场内外的每一张开放长桌上[cite: 2, 3]： 在那个第一次鼓起勇气向社区提交 PR 的高校学生身上[cite: 2]； 在那个耐心为新人做 Code Review、守护代码质量的社区 Maintainer 身上[cite: 2]； 在那些穿梭于会场与后台之间、亲手把一场开源大会从“方案”变成“现场”、散场后最后一个关灯的志愿者身上[cite: 2]。

结语#

每一代人都有每一代人的泥泞，每一代人也都有每一代人必须踩实的踏脚石[cite: 3]。

我们之所以对“开源下一代”满怀热望，不是因为相信未来会自动变好，而是因为我们深知：只要这套基于自由市场自愿交换、基于公开透明契约、基于同行声誉认同的开源机制仍在运转[cite: 4]，我们这一代人流过的汗、踩过的坑、写下的每一行开放代码，就不会随着某家公司的兴衰而湮灭。它们都将通过人类伟大的社会性，沉淀为河床上坚实的踏脚石[cite: 3]。

明天，好戏即将开场。让我们坐到同一张桌子上，踩稳脚下这一块石头，为下一代人，拿出办法来[cite: 2, 3]！
