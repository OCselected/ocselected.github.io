💡 今日思考#

开源治理的"AI Agent 时刻"

两篇论文同时关注 AI Agent 作为开源贡献者的治理问题，这不是巧合。当 AI Agent 开始提交代码、审查 PR、参与社区讨论，传统开源治理的"人本主义"假设正在被打破。

这带来了几个根本性问题：

  • 知识产权：AI Agent 生成的代码归谁所有？DCO（开发者原创证书）还适用吗？
  • 问责机制：如果 AI Agent 引入漏洞，谁来负责？开发者、模型提供商，还是 Agent 本身？
  • 社区规范：AI Agent 是否应该遵守行为准则？它们是否应该被列入贡献者名单？

这些问题没有现成的答案，但它们正在从理论探讨变为现实挑战。开源社区需要像当年应对 GPLv3 争议那样，进行一场新的制度创新对话。
