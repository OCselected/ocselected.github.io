「开源之道」 2026-11-22 搜集事件和材料

「开源之道」 2026-11-21 搜集事件和材料

今天四组材料指向同一处：「报告」正在取代「过程」成为信任的接口，而报告之所以能被信，靠的从来不是它写得诚恳，是有没有人有义务去核、有权利去驳。学术面是 12 万份开源缺陷报告的三年账本（AI 参与率 0.7%→8.3%，但「AI 发现型」报告获得的维护者动作反而更少，−0.93/报告）、编码 agent 工作报告忠实度实证（37.24% 含至少一条不实主张，且任务成功与报告忠实是两个独立属性）、以及把供应链测绘从「包」搬到「组织」的 AI 全栈数据集；新闻面是 FBI 通告里一个开源 AI 渗透工具 Artex 的「转闭源无效」；Project Pulse 看 eclipse-mosquitto 的 4,376:40 贡献者名单，与「撤权」这一条问责通道。

「开源之道」 2026-11-20 搜集事件和材料

今天三组材料指向同一件事：当「产出」与「释出」的成本同时被压到接近零，开源世界里区分「公地」与「单向发布」的信号就失效了。学术面是一篇以 OECD/Basel/FINMA 为基准的 DAO 治理风险测绘——去中心化不消灭权力，只是让权力换载体、失去单一问责点；新闻面是 Google 主组织 2,947 个仓库的许可证账本（Apache-2.0 占 81%，2026 年新建 128 个仓库里 85.9% 仍是 Apache-2.0），以及 Lovable 用 Rust 重写 Vite 开发服务器所暴露的「退出而不发声」新形态；Project Pulse 看一个 8 星的 google/iso-c-chaining——它有宣发级投入，却从没有人进来过。

「开源之道」 2026-11-19 搜集事件和材料

今天三组材料指向同一件事：AI 把产出成本压到接近零之后，制度要处理的不是「能不能做」，而是「谁来承担判断的责任、谁来付这笔账」。学术面只有一篇——蒂尔堡大学用 3,937 个 Python 仓库、约 97 万个 PR 做交错双重差分，证明 Copilot Reviewer 上线后维护者审阅的 PR 数 +10%、每条 PR 评审评论 +14%，而人类 PR 却变小了 14%。新闻面是一篇 1,281 分 / 670 条评论的 HN 辩论：「所有 AI 生成的代码都应当是开源的」。Project Pulse 对照 PyTorch 与 vLLM：同一基金会伞下、同一周，AI 共同署名率 9% vs 79%，治理答案一个是 32 行、一个是 165 行。

「开源之道」 2026-11-18 搜集事件和材料

今天三组材料指向同一件事：当 AI 让产出成本归零，制度要处理的是「谁来承担判断的责任」。学术面前后呼应——Törnberg 把奥斯特罗姆搬到 agent 之间，问「怎么防止一群会判断的东西互相印证同一个错误」，并自认第七条原则的边界（能实验效率、不能判定正当）；Albrecht 等人用同预算对照证明公地工具箱已能替代商业求解器，顺手用新下界推翻四个已发表的最优解。新闻面是一篇 311 分的 HN 热帖：AI 让「造新应用」的边际成本趋零，「让已有软件真的可用」的边际成本几乎没变，于是资源流向与价值分布彻底分岔。Project Pulse 实测 vLLM：81.7% 的提交带 AI 共同作者，而 245/245 全部带 Signed-off-by，纯 agent 无人类签署 = 0。

今天三条线问同一件事：当产出成本塌陷，「公地」靠什么维持。学术面给了模型（生成式 AI 一边消耗公地、一边在公地之上加装中控）与机制（划界/规制/合法化三种互补治理）；新闻面是一个真实的反面教材——两周 103 个 PR、把合并记录做成价目表的 AI agent，与 OpenSSF 把 23.8 万条恶意包数据接进八个生态；Project Pulse 实测 Kafka：名册三换三、AI 署名率 17%、而「谁合了什么」仍只由 10 个名字握着。
