【译】Linux基金会新任首席经济学家Frank Nagle的学术概览

2025年5月20日，Linux基金会宣布任命弗兰克·纳格尔（Frank Nagle）教授为其首席经济学家顾问。本文由「开源之道」整理并翻译，回顾纳格尔在开源软件经济、全球创业和创新生态方面的学术脉络与关键贡献。

2025年5月20日，Linux基金会宣布任命弗兰克·纳格尔（Frank Nagle）教授为其首席经济学家顾问1。这一重要任命凸显了开源软件日益增长的经济重要性，以及纳格尔教授在该领域的卓越专长。在这一职位上，纳格尔教授将主导基金会关于开源软件经济和社会影响的研究议程，尤其是在人工智能兴起的时代，旨在量化价值创造并促进开源生态系统的可持续增长。其目前工作的重点是通过合作、研究和倡导来扩大开源市场地位，尤其是在开源人工智能领域。

本文尝试回顾 Frank Nagle 的学术成果，包括重要的文章，以及对行业的突破和贡献评述。

重要文章介绍#

关注 Apache 软件#

2014年与沙恩·格林斯坦（Shane Greenstein）合著的《被忽视的数字内容与 Apache 的经济贡献》（“Digital Dark Matter and the Economic Contribution of Apache”）2，这项研究利用新颖的数据集估计，Apache 网络服务器的使用在美国私人固定投资中预包装软件库存的价值中，可能造成了20亿至120亿美元的错误计量。这表明大学和联邦资助在信息技术溢出效应方面存在着巨大的低估。这项工作为评估数字经济中非货币贡献的价值建立了关键方法论，为他后来对开源软件进行大规模估值奠定了基础。

企业通过支付员工贡献众筹公共产品来获得竞争优势#

《通过学习贡献：通过贡献众筹公共产品获得竞争优势》（“Learning by Contributing: Gaining Competitive Advantage Through Contribution to Crowdsourced Public Goods”）3（2018年）通过实证研究表明，贡献型企业从开源软件使用中获得的产生价值比"搭便车"的同行高出100%。这种"通过学习贡献"的论点是对开放创新经济学的深刻见解。它挑战了向公共产品贡献不带来私人利益的简单观点。

开源软件与全球创业#

2023年，与娜塔利亚·兰布尔·赖特（Nataliya Langburd Wright）和沙恩·格林斯坦合著发表了《开源软件与全球创业》（“Open Source Software and Global Entrepreneurship”）4。这项研究发现，一个国家 GitHub 参与度的增加会导致该国新科技企业的数量增加，特别是那些以使命为导向和全球化的企业。开源软件能够缩短创新软件模块的开发时间，消除知识财产谈判的麻烦，并降低软件开发融资的摩擦，从而促进创业活动。

量化开源软件价值#

2024年，纳格尔教授与曼努埃尔·霍夫曼（Manuel Hoffmann）和周亚诺（Yanuo Zhou）合著了《开源软件的价值》（“The Value of Open Source Software”）5。这项具有里程碑意义的论文发现，如果没有开源软件，全球经济在软件上的支出将增加3.5倍，相当于约9万亿美元的价值。如果每家公司都必须重写其使用的每个开源软件包，将耗资8.8万亿美元；如果只需一次性重建所有开源软件，则需41.5万亿美元。它为投资开源基础设施提供了具体的经济依据。

9万亿美元的估值不仅仅是一个数字；它从根本上改变了人们对开源软件的看法，使其从一种"免费"资源转变为一种不可或缺的、具有经济活力的全球公共产品。这种量化为增加投资和政策支持提供了有力的论据，将讨论从抽象的益处转向具体的经济必要性。从此，开源不再是模糊的、模棱两可的托辞，而是具有明确的数字量化。
