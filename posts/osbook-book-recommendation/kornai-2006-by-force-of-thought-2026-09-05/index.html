2026-09-05 「开源之道」·荐书：思想的力量 — 科尔奈#

内容概要#

科尔奈在《思想的力量》里做的不是"我的一生"，是**“我的信念如何被反复塑造”。这是一本"非常规"自传——不按时间顺序，按信念-怀疑-失望-新信念**的循环组织，每一章都对应一个具体的历史情境：匈牙利共产主义时期的社会主义计划、布达佩斯的地下经济研究小组、1968 年苏联入侵之后的信念崩塌、1989 年东欧剧变的意外胜利、以及他自己对"社会主义为何失败"的经典诊断（“短缺经济学"和"软预算约束”）。

他的核心判断在书里反复出现：信念不是被论证出来的，是被制度安排逼出来的。你在什么样的制度里工作、看什么样的数据、和什么样的同事合作，就决定了你相信什么。一个社会学家/经济学家的观点不是他个人意志的产物，是他的制度位置的产物——这一点在 NIE 的语境里，就是 Williamson 的 L1（社会嵌入） 与 L2（制度环境） 的联合效应。

书中还有一个反复出现的姿态：“我要保持移动”（Keep Movement）——不是指"我要一直做同一件事"，而是"我拒绝让自己的任何一个信念凝固成终局判断"。信念一旦凝固，就变成了意识形态；一旦保持移动，就变成了方法论。

一句话推荐#

「思想的力量」不是关于开源的书，但适兕开源之道的核心方法论——Keep Movement——原型就来自这里：智识的移动本身，就是抵抗意识形态化最有效的方式。

为什么值得读#

  • 它是 NIE 谱系中最容易被漏掉的一本书——教科书只教科尔奈的"短缺经济学"和"软预算约束"，但这两个概念都是他在《思想的力量》里被反复重塑的判断的产物。跳过这本书读科尔奈，就像跳过《存在巨链》读拉什迪。
  • 它给出了"信念制度论"的第一手证据——不是一个理论家声称"制度塑造信念"，而是一个制度经济学家的自证：“我在计划经济里相信计划经济，我在东欧剧变里突然相信市场，不是我的判断力变了，是我的制度位置变了。“这对大分流 2.0 的"为什么开源在中国不能工作"问题是一个直接的注脚。
  • 它把"移动"从道德姿态升级为认识论约束——“Keep Movement"不是"要积极进步”，是"不允许任何一个信念凝固成结论”。这正是适兕 2026-07-26 日读桥接中"开源的工作不是开拓，是启蒙"的智识基础：启蒙之所以是持续的工作，是因为任何"我已经启蒙了"的判断都会凝固。

为什么对开源社区如此重要？#

信念的制度化：开源社区同样在经历"制度生产信念”#

科尔奈在《思想的力量》里做了一件开源社区至今没有充分做的事情：追踪自己的信念是如何被制度环境一步步塑造的。他把"我在某个时刻相信什么"还原为"我在那个时刻身处什么样的制度里、看什么样的数据、和谁合作"。

开源社区同样在经历这套机制，但没有人系统地做这件事：

  • 1990 年代的开源开发者相信"软件应该自由"，因为他们身处互联网早期、身处 GNU 项目、身处 Stallman 的道德号召——不是他们个人意志，是他们的制度位置决定了他们相信什么；
  • 2010 年代的开源企业相信"开源是最好的营销"，因为他们身处 Linux 基金会、身处红帽的 IPO、身处硅谷的投资周期——同样不是判断力，是制度位置；
  • 2026 年的"中国开源"相信"开源是技术自主的战略工具"，因为他们身处信通院的行政体系、身处 AtomGit 的国产替代叙事、身处"出海"的行政修辞——同样不是判断力，是制度位置。

**同一个"开源"概念，在三种不同的制度位置里，产生三种完全不可通约的信念。**这是大分流 2.0 的核心命题——不同制度环境下，同一个词的含义是不同的。科尔奈这本书的价值，是把这个"信念的制度化"机制，作为一个自证的经验事实呈现出来，而不只是一个理论家的假设。

Williamson L1 / L2 的经验注脚#

Williamson 的四层框架里，L1（社会嵌入）和 L2（制度环境）最难处理，因为它们不直接观察，它们通过信念起作用。科尔奈在《思想的力量》里做的事情，本质上是给 L1 / L2 提供了一份自证的经验样本：

  • L1 是社会嵌入——你不是一个抽象的行动者，你嵌在一个具体的社会里；
  • L2 是制度环境——这个社会里的规则、惯例、奖惩结构在暗中决定你的可能行动集合；
  • L1 + L2 的联合效应是——你相信什么，不是你的自由意志，是你的制度位置的产物。

**开源社区的制度分析，为什么必须回到 L1 / L2？**因为 L3（治理机制）和 L4（资源配置）都是可观察的、可测量的，而 L1 / L2 只能通过"信念史"来推断。科尔奈这本书，是 L1 / L2 分析的一个可以直接引用的经验样本。

“Keep Movement"作为方法论，不是姿态#

适兕在 2026-07-26 日读中把"Keep Movement"确立为开源之道的核心原则。科尔奈在书里给这个概念一个精确的定位——它不是“要不断进步”、不是“要拥抱变化”、不是“要持续学习”，而是：

“不要让自己的任何一个信念凝固成终局判断。”

这个定位的强度比表面看起来大得多：

  • 一个"开源是自由软件"的信念，如果凝固了，就会遮蔽"开源也是商业模式”、“开源也是治理实验"等其他合理的判断；
  • 一个"开源在中国失败"的信念，如果凝固了，就会遮蔽"开源在中国的替代形态”（特许工程代码、局域网共享、赛博庄园）；
  • 一个"制度框架能解释一切"的信念，如果凝固了，就会遮蔽"技术文化 / 生态演化 / 政治经济"等其他有效的分析视角。

**“Keep Movement” 的深层含义是：任何分析框架本身都必须被允许被替换。**这正是开源之道的方法论伦理——不是谦虚的姿态，是一个必要的认识论约束。

与"框架误导"和"存在巨链"的谱系连接#

这三天（2026-09-03 到 2026-09-05）我们推荐的三本书，共同构成了一个思想史谱系：

  • 《存在巨链》(Lovejoy 1936)——西方的"信念"曾经是一个"宇宙论的等级"（人-动物-植物-石头），后来被砸碎成"多元的、共存的"框架。信念的制度化在这里表现为一个宇宙级的秩序。
  • 《与时俱进的启蒙》(徐贲 2020)——现代的"信念"被制度环境（教育、行政、媒体）生产，“框架误导"是它的病理学。信念的制度化在这里表现为一个社会级的机制。
  • 《思想的力量》(科尔奈 2006)——一个具体的制度经济学家自证：他的信念如何被他的制度位置塑造、崩塌、重新接住。信念的制度化在这里表现为一个自传级的证据。

**三本书，一个主题，三种尺度：宇宙级、社会级、个人级。**这是开源之道"思想史注脚"方法论的一个直接呈现——同一个问题（信念如何被制度塑造），在不同尺度上都有精确的经典文本可以引用。

关联阅读#

  • 《短缺经济学》(Kornai 1980) — 同一作者的另一本代表作，把"社会主义为何失败"用一个具体的制度机制（“短缺"作为常态、“软预算约束"作为根源）解释清楚。《思想的力量》是它的方法论前置。
  • 《存在巨链》(Lovejoy 1936) — 一个宇宙级的"信念谱系"如何崩解的历史。此前推荐
  • 《与时俱进的启蒙》(徐贲 2020) — “框架误导"作为社会级的"信念生产"机制。此前推荐
  • 《公共事物的治理之道》(Ostrom 1990) — 信念制度化的反面样本：Ostrom 的公地治理八原则证明，某些社区能够在制度之外维持一套自己的信念，不需要外部权威强加。
  • 《制度、制度变迁与经济绩效》(North 1990) — 新制度经济学的经典教科书，明确把"信念系统”（beliefs）作为制度变迁的核心变量，是科尔奈这一支谱系的直接继承者。

延伸思考#

追问一：如果科尔奈的"信念制度论"成立，那么"Keep Movement"能不能避免自己的"信念制度论”？

这是科尔奈给所有方法论者提出的最锋利的问题。如果信念是被制度塑造的，那么"我要保持移动"这个信念本身，也是被制度塑造的——它可能只是**“21 世纪西方社会科学界的制度位置”**给它生产出来的一个信念。

对开源之道的含义是：“Keep Movement” 不是终点，是起点——它是一个方法论约束，不是真理；它是一个自我祛魅的姿态，不是自我豁免的许可证。这正是徐贲在 2026-09-04 荐书里给所有启蒙者提出的最锋利的追问：“启蒙者自己也是需要启蒙的”。

追问二：如果科尔奈的智识移动是"个人意志 × 制度位置"的产物，那么开源社区的"移动"是可能性的吗？

科尔奈的移动有一个具体的历史契机——1968 年苏联入侵、1989 年东欧剧变、1990 年代冷战终结。这些外部事件打破了原有的制度位置，逼着人重新思考。

开源社区正在经历类似的历史契机吗？从 LLM / AI Agent 的爆发、到 Black Duck 退出中国、到 AtomGit 上线、到 MirrorZ 高校镜像化、到信通院行政标准——这些"制度位置"正在经历一次大规模的重置。这意味着：一个真正做制度分析的开源观察者，现在处于一个难得的"信念松动期”——不是任何"已经形成"的判断都有效，而是每一个信念都值得重新被追问。

这正是"开源之道"为什么必须保持"边缘观察者 + NIE 启蒙者"定位的时代意义——不是我们要多聪明，是时代给了我们一个重新提问的机会。

追问三：适兕的"思想是制度的源代码"命题，如何在科尔奈的框架里被重新理解？

适兕在 2026-07-27 日读中提出一个判断：”不是规则在动，是思想在动。“这句话在科尔奈的框架里有一个非常精确的对应：“思想"是 L1 / L2 层的信念系统，“制度"是 L3 / L4 层的治理机制。科尔奈这本书证明：L3 / L4 的变化（东欧剧变、计划经济崩溃），最终是由 L1 / L2 的变化（一代人对社会主义信念的崩塌）驱动的。

“思想是制度的源代码” —— 这个命题在 NIE 的四层框架里，就是"L1 / L2 是 L3 / L4 的前置变量”。没有信念的松动，就没有制度的变迁；反过来，任何试图绕过 L1 / L2、直接改造 L3 / L4 的制度工程，都是"极端现代主义”（Scott 1998）。

这为什么重要——因为它意味着开源之道对中国开源的诊断，不是"你的技术不行”、“你的治理不行”、“你的许可证不行”，而是：“你的 L1 / L2（社会嵌入 + 制度环境）没有松动，所以 L3 / L4（治理机制 + 资源配置）不可能真的改变”。任何试图跳过 L1 / L2 的开源改革尝试——不管是"开源 20 条"、“AtomGit 战略”、“信通院标准”——本质上都是制度工程学的一元化思维（Kornai 意义上的"soft budget constraint"）。
