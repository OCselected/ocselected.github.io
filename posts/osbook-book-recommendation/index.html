2026-10-23 「开源之道」·论文略读：印着 MIT 的箱子，法律上是不是 MIT？——宽松许可标签与合规载荷的断裂

Jewitt、Rajbahadur、Li、Adams、Hassan（Queen’s University，KDD 2026）审计了 124,278 条 dataset→model→application 供应链，发现只有 2.3% 的宽松许可数据集和 3.2% 的宽松许可模型同时具备许可证全文与版权声明；而当上游真的齐备时，归属声明传到下游的比例只有 27.59%（dataset→model）与 5.75%（model→application）。结论一句话：宽松许可的标签不是可执行的授权，许可证文件与声明文本而非元数据，才是法律真相源。

2026-10-22 「开源之道」·论文略读：圈的是地，还是圈地的权利？——第二次圈地运动与公共领域的建构

Boyle（杜克法学院，Law and Contemporary Problems 66:33-74, 2003）把数字时代的知识产权扩张命名为「第二次圈地运动」，并给出了一个比「反版权」更硬的判断：真正的危机不是公地被过度使用，而是公地被过度圈占；而公共领域必须像「环境」一样先被发明出来，才可能被拯救。对开源而言，这意味着开源许可证不是在放弃产权，而是在重新划定产权边界——但当许可证被证明管不住分发渠道与构建流水线时，圈地已经换了战场。

2026-10-21 「开源之道」·论文略读：Agent 优化了什么，又交代了什么？——1,130 对 1,130 的度量契约审计

Peng、Calvo、Kalu 与 Davis（Purdue Duality Lab, arXiv 2610.03969）用 1,130 份 agent 性能 PR 对 1,130 份人类性能 PR 做分层配平对照：合并率 54.4% vs 73.3%，但验证报告率 82.3% vs 80.6% 无统计差异。真正的差距在后面——有验证证据的 PR 里约一半根本没有量化指标，缓存类 PR 只有 17.7% 交代了权衡。这不是 agent 稀释质量，是开源从未为「性能主张」建立度量契约，而 agent 把这处空位照了出来。

2026-10-19 「开源之道」·论文略读：验证成本——AI 时代开源公地真正稀缺的东西

2026-10-17 「开源之道」·论文略读：网络安全开源的合规困境——当 39% 的文件没有署名
